# Changelog

## 0.2.1 — 2026-10-14

- Shortened the runtime entrypoint while retaining the complete operating model and focused references.
- Added role-aware entry so workers and reviewers preserve existing project ownership; retained confirmation gates and authorized continuation.
- Added project-scoped installation, loading checks, updates, version selection, and rollback guidance in both overviews.
- Added a filled first-project walkthrough and a dependency-free package checker for maintainers.
- Added contribution, release, and real-use evaluation guidance; clarified licensing, listing, and security-review limits.

See [validation](VALIDATION.md) for the evidence and untested boundaries of this release. A shorter entrypoint is not a measured token-saving claim.

## 0.2.0 — 2026-10-14

Expanded the skill into a complete project operating model: lead responsibilities, project/batch/task planning, continuous delivery, request routing, integration, reporting, cost, and continuity. Added independent behavioral exercises J–L and bounded editorial review.

## 0.1.1 — 2026-10-13

Established English as the canonical rule set, retained a Chinese overview, and exercised cumulative requirement reconciliation.

## 0.1.0 — 2026-10-13

Initial coordination package with ownership, delegation, reporting, recovery, templates, and scenario exercises. Historical version entries describe prior work; they do not imply that every version has a published GitHub Release.
